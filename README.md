# FinAI — Платформа банковской аналитики

FinAI — веб-приложение для анализа личных финансов. Пользователь загружает банковскую выписку (PDF/CSV), а платформа разбирает, нормализует, классифицирует и визуализирует финансовые операции — превращая сырой банковский экспорт в структурированный обзор расходов, подписок и практических рекомендаций.

## Что реализовано сейчас

Текущая кодовая база — **статический прототип фронтенда**. Все шесть страниц полностью оформлены и навигируемы. Все данные захардкожены в HTML.

**Реализованные страницы:**

| Страница | Файл | Назначение |
|----------|------|------------|
| Обзор | `reviewFin.html` | Финансовая сводка — баланс, сбережения, KPI доходов/расходов, график расходов с переключателем день/неделя, выбор месяца |
| Транзакции | `transactionsFin.html` | Реестр операций с фильтром по типу, выпадающим списком категорий, периодом, сбросом, пагинацией, экспортом CSV |
| Категории | `categoriesFin.html` | Разбивка расходов по категориям с управлением периодом и фильтрами |
| Подписки | `subscriptionsFin.html` | Активные подписки с фильтрами по категориям и сводкой стоимости за месяц/год |
| Инсайты | `insightsFin.html` | Рекомендации на основе ИИ и потенциал оптимизации |
| Импорт | `importFin.html` | Область загрузки выписки (только PDF/CSV) с краткими инструкциями |

### Ключевые файлы

**`assets/css/finai.css`** — Дизайн-система в CSS custom properties и утилитарных классах. Определяет палитру цветов (зелёный Emerald Slate `#00A551`, шкалы surface, семантические цвета), типографику (`display-hero`, `balance-lg`, `headline-lg`, `title-sm`, `body-md`, `label-caps`, `tabular-num`), отступы, скругления, тени и все стили общих компонентов: `.page-title`, `.btn-primary` / `.btn-secondary` / `.btn-ghost`, `.pill-group`, `.card`, `.kpi-plate` / `.kpi-item`, `.finai-select` / `.finai-select-menu`, `.tx-row`. Также включает систему появления страницы (`html{opacity:0}` → `html.layout-ready`) и блок `prefers-reduced-motion`.

**`assets/js/layout.js`** — Единый источник истины для общей навигации. На `DOMContentLoaded` вставляет левый Sidebar и заголовок TopDashboard на каждую страницу, отмечает активный пункт навигации на основе `<body data-page="…">`, затем показывает страницу через `html.layout-ready`. Содержит выпадающий список месяцев (`#topMonthMenu`) в TopDashboard.

**`assets/js/interactions.js`** — Лёгкий слой микро-взаимодействий:
- Универсальная система выпадающих списков (`.finai-select-menu`, `[data-dropdown-trigger]`, `.finai-option`) с закрытием по клику снаружи и Esc
- Выделение строки транзакции чекбоксом (`.tx-row` → `.is-selected`)
- Обработчик выбора месяца через `FinAI.onSelect()`

**`assets/js/tailwind-config.js`** — Кастомная тема Tailwind, расширяющая CDN-сборку с токенами цветов Emerald Slate, шрифтами (Inter, Manrope) и утилитами отступов/скруглений.

## Как запустить

Без шага сборки, без пакетного менеджера, без бандлера.

## Архитектура

- **Чистый HTML / CSS / JavaScript.** Без фреймворков (ни React, ни Vue, ни Angular). Без инструментов сборки.
- **Tailwind CSS через CDN** (`https://cdn.tailwindcss.com`) с кастомной темой в `tailwind-config.js`.

## Интерактивные функции (уже работают)

- **Навигация в сайдбаре** — переход по любой из 6 страниц
- **Выбор месяца в TopDashboard** — клик по "Сентябрь 2026" для выбора другого месяца (только UI-состояние, исторических данных нет)
- **Переключатель день/неделя** на графике расходов в Обзоре
- **Фильтр транзакций по типу** — Все / Расходы / Доходы / Переводы
- **Выпадающий список категорий** — фильтрация по категории
- **Выпадающий список периода дат**
- **Сброс фильтров** — возврат к состоянию по умолчанию
- **Пагинация** — постраничный просмотр статического набора из 8 записей
- **Экспорт CSV** — скачивание текущих транзакций в файле `.csv`
- **Выделение транзакции чекбоксом** — отмеченные строки получают зелёную подсветку
- **Управление периодом категорий** — Сентябрь / Август / Квартал
- **Фильтры категорий**
- **Фильтры подписок по категориям** — Все / Развлечения / Сервисы / AI / Спорт / Связь

## Статические / mock-данные

Все финансовые данные захардкожены в HTML:

- **8 транзакций** — 4 расхода, 1 доход, 1 перевод, 1 нераспознанный мерчант
- **Расходы по категориям** — Продукты, Еда и доставка, Покупки и т.д.


### Рекомендуемые API-эндпоинты

| Метод | Эндпоинт | Назначение | Замещает |
|-------|----------|------------|----------|
| `POST` | `/api/import` | Загрузка PDF/CSV выписки для разбора | Mock-результат импорта |
| `GET` | `/api/transactions` | Список транзакций (с фильтрацией по типу, категории, диапазону дат, пагинацией) | Статические строки транзакций |
| `GET` | `/api/categories` | Статистика расходов по категориям | Статические карточки категорий |
| `GET` | `/api/subscriptions` | Активные подписки со стоимостью | Статические карточки подписок |
| `GET` | `/api/insights` | Рекомендации на основе ИИ | Статические карточки инсайтов |
| `GET` | `/api/overview` | KPI дашборда — баланс, сбережения, доходы, расходы, данные графика | Статические KPI Обзора |

`GET`-эндпоинты должны принимать query-параметры для фильтрации: `?month=2026-09&type=expense&category=Продукты&page=1&limit=10`.

### Поток данных Фронтенд → Бэкенд

```
Пользователь
  ↓ нажимает "Загрузить выписку"
Фронтенд
  ↓ POST /api/import  (multipart/form-data: PDF или CSV файл)
Бэкенд
  ↓ Парсинг файла (извлечение текста из PDF / разбор CSV)
  ↓ Нормализация строк → канонический формат транзакции
  ↓ Классификация каждой операции:
  │   ├─ правила (словарь известных мерчантов)
  │   ├─ паттерны (MCC-коды, regex)
  │   └─ LLM (только для неясных операций)
  ↓ Сохранение транзакций
  ↓ Возврат: { importId, transactionsCount, categories: [...], ... }
Фронтенд
  ↓ Обновление списка транзакций, категорий, KPI
  ↓ Переход на обновлённый Обзор или Транзакции
```

### Где выполняется каждый этап

| Этап | Бэкенд | Фронтенд |
|------|--------|----------|
| Загрузка файла | Приём файла, валидация формата (только PDF/CSV) | `<input type="file">`, drag-and-drop UI |
| Парсинг | Извлечение текста из PDF, разбор CSV | — |
| Нормализация | Маппинг сырых строк в канонические поля | — |
| Классификация | Правила → словарь мерчантов → LLM | Отображение значка уверенности |
| Хранение | База данных (транзакции, категории, пользователи) | — |
| Аналитика | Агрегатированная статистика, обнаружение подписок | Графики, таблицы, KPI-карточки |
| Инсайты | Генерация рекомендаций | Отображение карточек инсайтов |

- **4 подписки** — Яндекс Плюс, ChatGPT, Яндекс Фитнес, МТС Premium
- **Инсайты** — 4 карточки рекомендаций с потенциалом оптимизации
- **KPI Обзора** — захардкоженные баланс, сбережения, итоги

Обработка файлов не реализована. Область загрузки на странице Импорт — только визуальная; перетаскивание или выбор файла ничего не делает.

- **Material Symbols** и шрифты **Inter / Manrope** через Google Fonts CDN.
- **Общий лейаут** внедряется врантайме через `layout.js` — каждый HTML-файл содержит только уникальный контент внутри `<div id="page-content">`. Sidebar и TopDashboard собираются JavaScript'ом, а не дублируются в каждом файле.
- **Навигация** работает через открытие соответствующей HTML-страницы (`href="transactionsFin.html"`). Активный пункт определяется по совпадению `data-page` на `<body>` с `data-nav` на каждой ссылке сайдбара.
- **Переходы между страницами** используют двухэтапное появление: страница начинается с `html{opacity:0}`, layout.js вставляет общие компоненты, затем добавляет `html.layout-ready`, что запускает плавное появление за 220ms. Это предотвращает мерцание сайдбара в промежуточном нестилизованном состоянии.
